# Python Expense Tracker

A beginner-friendly Python terminal application for tracking personal expenses.

## Features Planned

- Add expenses
- View expenses
- Show total spending
- Save expenses to a file
- Categorise expenses
- Search and filter expenses

## Technologies Used

- Python
- Git
- GitHub

## Project Goal

The goal of this project is to improve my Python programming skills while learning how to build and structure a real software project.
